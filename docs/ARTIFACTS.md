# Index of the published artifacts

Every file below is part of the thesis record and is kept unchanged: [`docs/artifacts.sha256`](artifacts.sha256) holds its SHA-256, and `python tools/manifest.py --check` (also a test) fails if any byte changes. This index only describes the files; it does not alter or reinterpret them.

"Consistent with the thesis" means that `python tools/verify_results.py` recomputes the thesis numbers (Tables 4.1 and 4.2, the decision-tree class counts) from the file. The script and the checks C1–C8 are described in its docstring; all 42 checks pass.

## Result tables (`results/tables/`)

| File | Content | Status |
|---|---|---|
| `exp1_failure_distance_summary.csv` | per model and goal: number of strict failures and their mean / min / max final distance (no row = no failure) | consistent with the thesis: failure counts give every per-goal success rate of Table 4.1 (C1) and the tree class counts (C5) |
| `combined_overview.csv`, column `Exp1` | overall strict success per model | consistent with the thesis: mean of the three per-goal rates, Table 4.1 *Overall* (C2) |
| `exp1_input_sensitivity_goal_1_0.csv` | goal B: success rate, average distance, number of failures, input ranges of the failures | consistent with the thesis: Table 4.1 and 4.2 goal B columns (C3) |
| `exp1_theta_sensitivity.csv` | strict success per 8 orientation bins for each model and goal (a 3 × 3 goal grid, of which the three thesis goals are populated) | consistent with the thesis: bin-weighted rates give Table 4.1 (C6); 200 inputs per cell, same bins for every model (C7) |
| `exp1_bad_theta_bins.csv` | orientation bins with low success | exactly the bins of `exp1_theta_sensitivity.csv` with success below 80 % (C8) |
| `summary_avg_success.csv` | per model, rows `Exp1` and `Exp2`: `SuccessRate`, `AvgDist` | `AvgDist` of the `Exp1` rows is consistent with Table 4.2 *Overall avg* (C4). The `SuccessRate` column and the `Exp2` rows do not match Tables 4.1–4.2, and the repository does not document how they were computed |
| `combined_overview.csv`, columns `Exp2`, `Delta_Exp2_minus_Exp1` | per model | `Exp2` is the per-model mean of `exp2_goal_summary_per_model.csv`; `Delta` = `Exp2` − `Exp1`. These values do not match the thesis tables |
| `exp2_goal_summary_per_model.csv` | per goal and model: `SuccessRate` (0 or 100 %) and `AvgDist` (0.06–0.36 m) | does not match Tables 4.1–4.2; production settings not documented in this repository |
| `exp2_goal_mean_over_models.csv` | per goal: mean of the file above over models | derived from `exp2_goal_summary_per_model.csv` |
| `summary_table.csv` | success rate as a function of the distance threshold (0–1 m), per model | listed in the README as a per-run output; its average distances (e.g. 0.62 m for `closs1`) differ from Table 4.2 (0.482 m) |

## Notes for readers

- In the demo notebook, the risk-map cell plots the share of trajectories with `distance >= 0.50 m` (the soft *failure* class) under the colour-bar label "Strict Failure Rate". The notebook uses synthetic data and is kept unchanged.
- The README's *Getting Started* says that `src/evaluate.py` writes `exp1_inputs.npy`, `exp1_samples.csv` and `exp2_goal_summary.csv` under `--output_dir`; the code writes them under `<output_dir>/tables/` (figures go to `figures_exp1/` and `figures_exp2/`).
